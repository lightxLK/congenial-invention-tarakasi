Exhibition About Privacy

Privacy

This site collects nothing about you. It has no accounts, forms, advertising, analytics or tracking scripts, and it sets no cookies.

Third parties

All fonts, images and code are served from the same domain you are visiting. The page makes no requests to third-party services, so no third party receives your IP address or browsing information from this site.

Server logs

As with any website, the hosting provider's servers record standard access logs (IP address, time, requested page, browser type) for security and operation. The site owners do not use these logs to identify or profile visitors.

External links

Citations open the websites of the original sources, which have their own privacy practices.

Changes

If analytics, forms or any other data collection is ever added, this notice will be updated first. Read more about the exhibition.
